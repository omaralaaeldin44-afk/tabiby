للمطورين والمستشفيات

المشروع مفتوح للتطوير. الكود على GitHub.

تشغيل خادم المستشفى

الخادم لا يحتاج مكتبات خارجية. يكفي Node.js 18 أو أحدث:

git clone https://github.com/omaralaaeldin44-afk/tabiby
cd tabiby
npm start   # http://localhost:3000

افتح العنوان من هواتف المرضى والأطباء على نفس الشبكة، أو اكتبه في «الإعدادات» داخل التطبيق.

إضافة حساب حقيقي (يعطّل الحسابات التجريبية):

npm run add-staff -- dr.ahmed doctor "كلمة-مرور-قوية" "د. أحمد"
npm run add-staff -- mona.signs interpreter "كلمة-مرور-قوية" "منى — مترجمة إشارة"

الأدوار: doctor وnurse وinterpreter وadmin. فيديوهات الشكاوى تُحفظ في data/requests/ وتُحذف بعد 7 أيام.

🤟 إضافة فيديوهات لغة الإشارة

نحتاج فيديوهات حقيقية لشخص يؤدي لغة الإشارة المصرية، يراجعها مختص. طريقتان للإضافة:

  1. داخل التطبيق قبل البناء

    ضع الملف في www/videos/ باسم معرّف الجملة، مثل p1.mp4 لجملة «أين تشعر بالألم؟». المعرّفات ظاهرة في لوحة الإدارة.

  2. من لوحة الإدارة

    ارفع الفيديو من الهاتف مباشرة. يُحفظ على ذلك الجهاز.

نصيحة للتصوير: خلفية سادة، إضاءة أمامية، يظهر الوجه واليدان كاملين، ومدة قصيرة لكل جملة.

📱 تحويل التطبيق إلى APK

المشروع مجهّز بـ Capacitor. يحتاج JDK 17 وAndroid SDK:

npm install
npx cap add android
npm run apk:debug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk

أو افتح المشروع في Android Studio بالأمر npm run cap:open وابنِ من هناك.

🗺️ ما يحتاج تطويرًا

  • تصوير فيديوهات الإشارة المصرية ومراجعتها.
  • مزامنة مركزية للمحتوى بين الأجهزة (حاليًا تصدير/استيراد ملف).
  • ربط تنبيه المساعدة بنظام الاستدعاء في المستشفى.
  • تخزين دائم للمقابلات إن احتاجته المستشفى، مع سياسة حذف واضحة.
  • اختبار مع مرضى صم حقيقيين ومراجعة سهولة الاستخدام.
