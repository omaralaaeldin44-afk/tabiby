# طبيبي يفهمني – Tabibi Yefhamni

تطبيق عربي (RTL) لمساعدة المرضى الصم وضعاف السمع في مصر على التواصل مع الأطباء والممرضين عند عدم وجود مترجم لغة إشارة.
هو تطبيق ويب تقدّمي (PWA) يعمل دون إنترنت، وجاهز للتحويل إلى APK عبر Capacitor. لا يقدّم تشخيصًا ولا علاجًا ولا جرعات.

## الموقع
- `site/`: موقع تعريفي من 5 صفحات (الرئيسية، المميزات، كيف يعمل، الخصوصية، للمطورين). يُولَّد بالأمر `python3 scripts/build-site.py`.
- عند الدفع إلى `main` ينشر GitHub Actions الموقع على Pages، والتطبيق تحت `/app/`.
- لتفعيل النشر: Settings → Pages → Source: **GitHub Actions** (المستودع يجب أن يكون عامًا على الخطة المجانية).

## التشغيل
```bash
npm start            # يشغّل الخادم على http://localhost:3000 (لا يحتاج npm install)
```
- افتح الرابط على الهاتف (نفس الشبكة) لتجربة التطبيق. عند فتحه من الخادم يتصل تلقائيًا بنظام المقابلات.
- بدون الخادم (أي استضافة ثابتة مثل GitHub Pages) يعمل في **الوضع المحلي**، ويمكن ربط هاتف المريض بهاتف الطبيب **مباشرة دون إنترنت** (WebRTC) بمسح رمزي QR، على نفس الواي فاي أو نقطة اتصال. الكود في `www/js/direct.js`.
- حسابات تجريبية: `dr.demo / Demo@Doctor1` ، `nurse.demo / Demo@Nurse1` ، `interp.demo / Demo@Interp1` (مترجم إشارة) ، `admin.demo / Demo@Admin1`.
- حسابات حقيقية: `npm run add-staff -- <user> <doctor|nurse|interpreter|admin> <password> "<الاسم>"` ثم أعد تشغيل الخادم (يُنشئ `data/staff.json` ويعطّل الحسابات التجريبية).

## إضافة فيديوهات لغة الإشارة
ضع ملفات حقيقية (mp4/webm) لشخص يؤدي لغة الإشارة المصرية في `www/videos/` بنفس معرّف الجملة، مثل `www/videos/p1.mp4`.
أو ارفعها من لوحة الإدارة (تُحفظ على الهاتف). لا توجد أي فيديوهات في المشروع الآن؛ تعرض الشاشات «الفيديو غير متوفر حاليًا».

## تصدير APK
```bash
npm install
npx cap add android
npm run apk:debug      # الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```
يتطلب JDK 17 وAndroid SDK (أو افتح المشروع بـ `npm run cap:open` وابنِ من Android Studio).
لربط التطبيق بالخادم من الـAPK: الإعدادات ← عنوان الخادم (مثل `http://192.168.1.10:3000`). الإعداد يسمح بـ HTTP داخل الشبكة المحلية؛ في الإنتاج استخدم HTTPS.

## فيديو الشكوى والمترجمون
- المريض يسجّل فيديو بالإشارة (حتى 90 ثانية، بدون صوت) ويوافق على عرضه، فيصل لـ«بوابة المترجمين» (`#/interpreter`)، ويعود الرد في «طلباتي».
- طلب «موعد عيادة مع مترجم» يصل لنفس البوابة.
- يحتاجان خادم المستشفى. الفيديوهات تُحفظ في `data/requests/` وتُحذف بعد 7 أيام أو عند حذف المريض لها.

## الأمان والخصوصية
- الغرف في ذاكرة الخادم فقط وتُحذف بعد 12 ساعة أو عند إنهاء المقابلة. الأعراض لا تُرسل إلا بعد موافقة المريض، ولا يقرؤها إلا موظف مسجّل الدخول (طبيب/ممرض).
- كلمات المرور مشفّرة بـ scrypt، مع حد للمحاولات وانتهاء الجلسة، وخروج تلقائي بعد 15 دقيقة.
- **الوضع المحلي تجريبي**: الحماية فيه على مستوى الواجهة فقط ولا تُعد أمانًا حقيقيًا. للاستخدام الفعلي شغّل الخادم خلف HTTPS.
- لوحة الإدارة تحفظ التعديلات على الجهاز (تصدير/استيراد JSON)؛ المزامنة المركزية للمحتوى غير مبنية بعد.
